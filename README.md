## Overview

The KAJAL backend provides a reliable foundation for building maintainable and scalable APIs. It includes environment validation, database integration, application health monitoring, and standardized development tooling.

## Technology Stack

| Category          | Technology      |
| :---------------- | :-------------- |
| Framework         | NestJS          |
| Language          | TypeScript      |
| ORM               | Prisma          |
| Database          | PostgreSQL      |
| Validation        | Zod             |
| Health Monitoring | NestJS Terminus |
| Linting           | ESLint          |
| Formatting        | Prettier        |
| Testing           | Jest            |

## Core Capabilities

- **Modular Architecture** — A structured foundation for maintainable backend services.
- **Environment Validation** — Validates configuration variables with Zod.
- **Database Integration** — Type-safe database access through Prisma and PostgreSQL.
- **Health Monitoring** — Application health checks using NestJS Terminus.
- **Code Quality** — Consistent code standards through ESLint and Prettier.
- **Automated Testing** — Testing infrastructure powered by Jest.
