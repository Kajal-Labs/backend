# Backend

Backend service built with **NestJS**, **TypeScript**, **Prisma**, and **PostgreSQL**.

This repository contains the initial backend project setup, environment validation, database configuration, health checks, and development tooling.

## 🛠️ Tech Stack

| Technology          | Purpose                |
| ------------------- | ---------------------- |
| **NestJS**          | Backend framework      |
| **TypeScript**      | Programming language   |
| **Prisma**          | ORM / database access  |
| **PostgreSQL**      | Database               |
| **Zod**             | Environment validation |
| **NestJS Terminus** | Health checks          |
| **ESLint**          | Code linting           |
| **Prettier**        | Code formatting        |
| **Jest**            | Testing                |
